# Моё время

Независимые таймеры и статистика. Статическое приложение без сервера и внешних зависимостей.

## Android

Откройте https://nayutalienx.github.io/multi-timer/ в Chrome и выберите «Установить приложение» / «Добавить на главный экран» в меню браузера. После первого успешного открытия и загрузки офлайн-кэша приложение работает без сети.

Время старта сохраняется на устройстве. После закрытия приложения или перезагрузки телефона отсчёт восстанавливается по часам устройства. Фоновые будильники и уведомления не предусмотрены.

Данные находятся только в браузере, не отправляются на GitHub и не синхронизируются между устройствами. Очистка данных сайта удаляет таймеры. Регулярно скачивайте JSON-копию в настройках. Для переноса из HTML-файла экспортируйте JSON в старой версии и импортируйте его на сайте.

## Публикация

GitHub Pages публикует корень ветки `main`. После изменения файлов сделайте commit и push. При изменении офлайн-ресурсов увеличивайте версию `CACHE` в `sw.js`.
